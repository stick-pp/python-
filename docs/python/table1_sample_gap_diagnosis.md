# Skinner (2008) Table 1 样本量差异核查文档

本文只核查 Table 1 的数据清洗与样本进入口径，不修改 `replicate_skinner_2008.py`，也不修改任何原始数据或输出数据。

说明：当前 Python 代码中的股利变量为 `dvc`，即 Compustat 普通股现金股利。下文所称“股利”均指该现金股利口径，不是股票股利。

## 1. 原论文处理口径与当前复现口径

### 1.1 Table 1 原论文口径

根据项目中 Skinner (2008) 复现规范和 Table 1 目标数，原论文 Table 1 的核心口径可概括为：

1. 使用年度公司数据构造公司-财政年度样本。
2. 排除金融行业和公用事业行业。
3. Table 1 分四个 10 年窗口：
   - 1980-1989
   - 1985-1994
   - 1990-1999
   - 1995-2004
4. 每个窗口按公司在窗口内的股利支付年份数和股票回购年份数分组。
5. 支付年份数基于观察到的正支付记录累计。
6. Table 1 公布的窗口公司总数为：

| 窗口 | 原论文公司数 |
|---|---:|
| 1980-1989 | 5,690 |
| 1985-1994 | 6,622 |
| 1990-1999 | 7,744 |
| 1995-2004 | 7,595 |

原论文更可能使用的是可交易普通股公司的股票层样本宇宙，而不仅是 Compustat 公司层样本。当前原始数据缺少 CRSP/CCM 股票层筛选字段，因此无法完全复刻这一层口径。

### 1.2 当前 Python 复现口径

当前 Python Table 1 口径如下：

1. 读取 `2.csv` 和 `ajex.csv`，按 `gvkey + datadate` 合并。
2. 保留：
   - `consol = C`
   - `indfmt = INDL`
   - `datafmt = STD`
   - `curcd = USD`
   - `fic = USA`
3. 行业筛选：
   - 构造 `sic_use = sich` 优先，`sich` 缺失时用 `sic` 补充。
   - 按 `sic_use` 排除 6000-6999 金融业和 4900-4999 公用事业。
4. 股利：
   - `dividend = dvc`
   - `dvc > 0` 记为股利支付年份。
   - `dvc = 0` 记为非支付年份。
   - `dvc` 缺失保持缺失，不填 0。
5. 回购：
   - 优先使用 `tstkc_t - tstkc_t-1`。
   - 当连续两年 `tstkc` 均真实观察为 0 且 `prstkc`、`sstk` 完整时，使用 `prstkc - sstk`，并标记为 `retirement_method`。
   - 当库存股变化不可观察但 `prstkc`、`sstk` 完整时，使用 `prstkc - sstk`，并标记为 `cashflow_fallback`。
   - `cashflow_fallback` 没有被标记为注销法。
6. Table 1 样本进入：
   - 只要求公司在对应 10 年窗口内至少有 1 个清洗后的公司-年度观察。
   - 不要求公司完整存在 10 年。
   - 不要求所有实际存在年份的股利状态和回购状态都完整可判定。
   - 部分年度支付状态缺失不会导致整家公司退出。
7. Table 1 分组：
   - 股利年份分组：`0`, `1-4`, `5-9`, `10`
   - 回购年份分组：`0`, `1-4`, `5+`
   - 这些是表格展示分组，不是用支付年份上下界处理缺失的旧逻辑。

## 3. 从数据清洗角度核查

### 3.1 与原论文口径一致或基本一致的部分

当前代码在以下方面与复现规范一致：

1. 使用 `gvkey + fyear` 作为公司-财政年度唯一键，并检查重复。
2. 使用 `sich` 优先、`sic` 补充的 `sic_use` 做行业筛选。
3. 排除金融业和公用事业。
4. `dvc` 缺失不填 0。
5. `tstkc` 滞后值按同一 `gvkey` 的精确 `fyear - 1` 匹配，不使用简单 `shift(1)`。
6. 负回购值在成功构造后截为 0。
7. 1969、1977、1979 等历史年份在清洗后仍保留，滞后变量是在正式分析窗口截取前构造。

### 3.2 与原论文股票层样本可能不一致的部分

当前 `2.csv` 字段中没有以下 CRSP/CCM 股票层筛选变量：

| 字段 | 当前 `2.csv` 是否存在 |
|---|---|
| `permno` | 否 |
| `permco` | 否 |
| `linktype` | 否 |
| `linkprim` | 否 |
| `shrcd` | 否 |
| `exchcd` | 否 |
| `iid` | 否 |

因此当前复现不能执行这些常见股票层限制：

1. 只保留可与 CRSP 成功链接的 Compustat 公司。
2. 只保留普通股股票。
3. 只保留主要上市证券或主要股票链接。
4. 只保留 NYSE/AMEX/NASDAQ 等交易所样本。
5. 排除非普通股、非主要证券、OTC 或无法有效链接的公司。

这会直接导致当前样本比原论文更宽。该问题会同时放大股利公司和回购公司数量，因为进入 Table 1 的公司基数已经偏大。

### 3.3 `cashflow_fallback` 对回购数量的影响

当前代码允许在库存股变化不可观察但 `prstkc`、`sstk` 完整时使用 `cashflow_fallback`。该逻辑会增加可观察回购年份，尤其在早期窗口影响较大：

| 窗口 | `cashflow_fallback` firm-years | 正回购 fallback firm-years | 有正回购 fallback 的公司数 | 当前有回购公司数 | 去掉 fallback 后有回购公司数 |
|---|---:|---:|---:|---:|---:|
| 1980-1989 | 18,672 | 3,181 | 1,948 | 4,405 | 3,472 |
| 1985-1994 | 5,501 | 546 | 493 | 4,536 | 4,245 |
| 1990-1999 | 6,132 | 499 | 444 | 5,083 | 4,878 |
| 1995-2004 | 5,056 | 376 | 322 | 5,222 | 5,073 |

因此，若原论文没有在库存股变化不可观察时使用同样的现金流替代测量，当前代码的回购年份数会偏高。这个因素主要解释“回购”方向的偏大，不能解释股利方向也偏大的事实。

## 4. 从样本进入口径角度核查

### 4.1 当前进入口径

当前 Table 1 的进入条件是：

```text
公司在该 10 年窗口内至少有 1 个清洗后的公司-年度观察。
```

当前代码没有使用以下条件作为主样本进入限制：

```text
div_valid_years = firm_years
rep_valid_years = firm_years
```

也就是说，公司只要进入窗口，即使部分年份股利状态或回购状态缺失，也不会整家公司退出。

### 4.2 支付状态完整性敏感性

如果只作为敏感性检查，临时要求“公司实际存在年份内股利状态和回购状态均完整”，窗口公司数会变为：

| 窗口 | 当前进入口径 | 支付状态完整才进入 | 原论文公司数 | 当前差异 | 完整状态口径差异 |
|---|---:|---:|---:|---:|---:|
| 1980-1989 | 9,790 | 6,494 | 5,690 | +4,100 | +804 |
| 1985-1994 | 10,961 | 6,984 | 6,622 | +4,339 | +362 |
| 1990-1999 | 11,561 | 6,916 | 7,744 | +3,817 | -828 |
| 1995-2004 | 11,230 | 7,094 | 7,595 | +3,635 | -501 |

这个结果说明：

1. 放松支付状态完整性确实会增加 Table 1 公司数。
2. 但它不能稳定解释所有窗口的差异。
3. 后两个窗口如果要求支付状态完整，反而低于原论文公司数。
4. 因此，样本进入口径不是数据量过大的唯一原因，也不是最主要原因。

## 5. 可能原因排序

### 原因 1：缺少 CRSP/CCM 股票层筛选，最可能是主因

这是最重要的原因。

当前数据是 Compustat 公司层样本，缺少 `permno`、`shrcd`、`exchcd`、`linktype`、`linkprim` 等字段，因此不能把样本限制到原论文更可能使用的“可交易普通股公司”宇宙。

结果是：

1. 很多没有有效 CRSP 普通股链接的 Compustat 公司仍进入 Table 1。
2. 非主要证券、非普通股、OTC 或交易所口径不符合的公司无法被排除。
3. Table 1 的总公司数、股利公司数和回购公司数都会偏大。

这与当前现象一致：不是只有回购偏大，而是 Table 1 的整体公司基数明显偏大。

### 原因 2：当前 Table 1 入口允许部分支付状态缺失公司进入

当前入口不要求支付状态完整，这会增加进入 Table 1 的公司数。

但敏感性检查显示，该因素只能解释一部分差异，且解释方向不稳定：

1. 1980-1989 和 1985-1994 中，完整状态口径仍高于原论文。
2. 1990-1999 和 1995-2004 中，完整状态口径低于原论文。

所以它不是最主要原因。

### 原因 3：`cashflow_fallback` 会放大回购年份数

`cashflow_fallback` 对早期窗口回购公司数影响明显。1980-1989 窗口中，去掉 fallback 后，有回购记录的公司数从 4,405 降至 3,472。

因此，如果原论文严格要求库存股路径或明确注销法识别，而不接受库存股不可观察时的现金流替代测量，则当前回购分组会偏大。

但该原因主要影响回购，不解释股利公司数和总公司数偏大。

### 原因 4：Compustat 数据版本和抽取范围更宽

当前原始文件含 302,231 个 firm-years、26,256 家公司。数据库后续回填、历史覆盖扩展、死档/非活跃公司保留方式都可能使当前 Compustat 样本与 Skinner (2008) 当年使用的数据版本不同。

这通常会扩大样本，尤其是较小公司和历史短公司。

## 6. 总体判断

仅针对 Table 1，当前 Python 代码在“支付变量构造”和“窗口内支付年份累计”方面基本符合修订后的复现规范，但与原论文完整样本宇宙仍不完全一致。

最大的不一致不在 Table 1 分组代码本身，而在数据源层面：当前只有 Compustat 公司层数据，没有 CRSP/CCM 股票层筛选。因此，当前样本比原论文更宽，导致股利和回购相关公司数都偏大。

如果一切以原论文为标准，后续应优先确认并补齐原论文使用的股票层筛选条件；在没有 CRSP/CCM 变量的情况下，不应在 Python 中自行发明替代筛选规则。
