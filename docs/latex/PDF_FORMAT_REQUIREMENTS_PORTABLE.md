# PDF 格式要求（可迁移版）

本文档只规定最终 PDF 的排版与视觉格式要求，不包含数据清洗、回归口径、正文内容或代码实现要求。

## 1. 模板与编译

- PDF 应使用 LaTeX 生成，推荐采用 ElegantLaTeX / ElegantPaper 模板。
- 中文报告应使用支持中文的编译链，例如 XeLaTeX。
- 最终 PDF 应保持正式学术论文风格，避免幻灯片式、网页式或截图拼贴式排版。
- 图表、表格、标题、脚注和页码应由 LaTeX 原生排版生成；不得直接粘贴 notebook、控制台或软件截图作为表格。

## 2. 页面与整体版式

- 页面使用 A4 论文版式。
- 正文应保持适当页边距、行距和段落间距，保证中文阅读舒适。
- 标题、作者信息、摘要、关键词、章节标题、正文、图表标题和注释之间应有清晰层级。
- 页码应连续、位置统一。
- 不应出现明显空白页、文字重叠、图表溢出页面或注释被截断。

## 3. 表格格式

- 表格风格必须严格模仿原论文的学术表格格式。
- 表格应水平居中放置在 PDF 页面中。
- 使用正式三线表或接近原论文的横线结构，避免全网格线、彩色底纹和电子表格截图风格。
- 表题应置于表格上方，编号连续，标题简洁明确。
- Panel 标签、列标题、行标题、横线、括号内标准误、显著性标记和表下注释应尽量贴近原论文。
- 回归表中系数与标准误应上下排列，标准误用括号包围。
- 显著性标记应统一，例如 `*` 表示 1% 显著，`†` 表示 5% 显著；表下注释必须解释标记含义。
- 宽表应通过缩小字号、调整列距、拆分 panel 或分成多张表处理，但不得牺牲可读性。
- 表格不得超出页边距。

## 4. 图形格式

- 图形应插入高分辨率 PDF 或 PNG 文件，优先使用矢量 PDF。
- 图形应水平居中，宽度与正文版心协调。
- 图题应置于图形下方，编号连续，标题简洁明确。
- 坐标轴、图例、线型、注释和单位应清晰可读。
- 图形不得模糊、拉伸变形或被裁切。
- 多图连续排版时，应保证图题与对应图形在视觉上明确对应。

## 5. 图表位置

- 表格和图形应作为 LaTeX 浮动体或等价结构插入。
- 表格应尽量靠近首次讨论位置，但以版面完整和可读性优先。
- 重要表格应位于页面中部或视觉中心区域，避免贴近页边或被分页切断。
- 图表之间应保留足够垂直间距，避免标题、注释和正文互相挤压。

## 6. 字体与文字

- 正文、标题、表格、图题和注释的字体应统一、清晰。
- 表格和图注可使用较小字号，但必须保证打印或屏幕阅读可辨。
- 中英文、变量名和数学表达式应排版一致。
- 变量名、代码式变量和公式建议使用等宽字体或数学字体，例如 `PRCC_F`、`IB - 0.6 x SPI`。
- 中文标点、英文标点和空格应保持统一，不得出现乱码。

## 7. 最终检查

- 编译最终 PDF 后，应至少检查：
  - 首页标题、摘要、关键词和章节开头是否正常。
  - 每张图是否显示完整、清晰、未裁切。
  - 每张表是否居中、未越界、注释完整。
  - 页码是否连续。
  - 是否存在空白页、过大留白、重叠、乱码或缺字。
- 如有条件，应将 PDF 渲染为图片逐页检查，而不只依赖 LaTeX 编译成功。
