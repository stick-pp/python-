# LaTeX style requirements

These requirements apply to the final Skinner (2008) replication report.

## Tables

- Table formatting must closely imitate the original Skinner (2008) paper.
- Use formal academic table layout, not screenshot-style output.
- Tables should be horizontally centered in the PDF.
- Captions, panel labels, horizontal rules, notes, and significance markers should follow the original paper's style as closely as the available replicated outputs allow.
- Wide tables should be resized or split into panels while preserving readability and original-paper structure.

## Figures and placement

- Figures and tables must be inserted as native LaTeX floats or included high-resolution PDF/PNG assets.
- Do not use notebook screenshots or console output in the report.
